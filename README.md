Оператор-источник, всё это через веса

-------АЛГОРИТМ
1. Сначала определяется лид по external_id, если не найден, то по phone, если нету, то создаётся новый лид
2. Задаем каждому оператору для каждого источника числовой вес, работал по примеру A=25% (10/40), B=75% (30/40), 40 обращений
3. Создаётся взвешенный список, где каждый оператор повторяется weight раз, потом из этого списка случайно выбирается оператор по весам, ну и соответственно случайный выбор даёт 25 на 75
4. Также у каждого оператора есть load_limit, current_load, при выборе оператора эти параметры учитываются - если оператор достиг лимита - ВЫЧЕРКИВАМ
5. Если операторов нет, то обращение создаётся без оператора, оно сохраняется в БД
